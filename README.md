> **Healthcare & Medical Supply Solutions**  
> Multan, Pakistan • Serving 50+ Public & Private Healthcare Institutions Nationwide

## 🌟 Overview

This repository contains the complete, modern, fully-responsive corporate web portal built for **M/S JAMEEL SONS**, developed directly from their official corporate profile documentation (`MS Jameel Sons Profile.pdf`).

The website is engineered with modern semantic HTML5, high-performance modular CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism), and vanilla JavaScript. It delivers lightning-fast loading speeds, zero build friction, 100% mobile responsiveness, and high conversion for hospital institutional procurement.

## 💻 How to Preview Locally

Because the project uses standard web technologies without heavy node bundlers, you can preview it immediately:

### Option 1: Direct File Launch
Double-click `index.html` in Windows Explorer or open it directly in Chrome, Edge, Firefox, or Safari:
```text
file:///D:/GitHubProjects/ms-jameel-sons-website/index.html
```

### Option 2: Local Python Server (Recommended)
Open PowerShell or Terminal in the project directory:
```powershell
cd D:\GitHubProjects\ms-jameel-sons-website
python -m http.server 8000
```
Then visit: `http://localhost:8000`

## 🌐 Deployment Options

### 1. GitHub Pages (Free)
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial release of M/S Jameel Sons website"
   ```
2. Push to a GitHub repository.
3. In repository settings, navigate to **Pages** and set the source branch to `main` (root `/`).

### 2. Netlify / Vercel
- Drag and drop the `ms-jameel-sons-website` folder directly into [Netlify Drop](https://app.netlify.com/drop) or import into Vercel. No build step or environment variable required.

### 3. cPanel / Apache / Nginx / Hostinger
- Upload the contents of `ms-jameel-sons-website` directly into your web root (`public_html/`).
